# Pruebas manuales

Lista de comprobaciones manuales que no se pueden automatizar fácilmente con JUnit (dependen del juego). Se amplía en cada fase.

## Fase 0 — Proyecto base

- [ ] `./gradlew build` termina sin errores.
- [ ] `./gradlew runClient` arranca el juego y StageLite aparece en la lista de mods.
- [ ] La pestaña creativa de StageLite aparece en el inventario creativo (vacía por ahora).
- [ ] `./gradlew runServer` arranca un servidor dedicado sin errores relacionados con el mod.
